# Online Book Store

## Project Description

Online Book Store is an Agile Software Project developed using Jira and integrated with a DevOps CI/CD pipeline using GitHub Actions.

## Agile Methodology

The project follows the Agile Software Development Lifecycle.

### Agile Lifecycle

1. Requirement Analysis
2. Product Backlog
3. Sprint Planning
4. Development
5. Testing
6. Sprint Review
7. Sprint Retrospective
8. Release

## Jira Project

Project: Online Book Store 2.0

Jira Project Key: OBS2

### Sprint Workflow

To Do → In Progress → Testing → Done

## Features

- User Registration
- User Login
- View Books
- Search Books
- Book Database
- Login Validation

## Technology Used

- Jira – Agile project management
- GitHub – Source code management
- GitHub Actions – CI/CD
- Java – Programming language
- Maven – Build and dependency management

## CI/CD Pipeline

The GitHub Actions pipeline performs:

1. Checkout Code
2. Setup Java
3. Build and Test
4. Package

## Project Objective

To study and implement the Agile Software Project Lifecycle using Jira and integrate it with a DevOps CI/CD pipeline.
